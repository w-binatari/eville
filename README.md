# HEROCK E-VILLE ACADEMY Website

Modern Next.js marketing site for HEROCK E-VILLE ACADEMY.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Lucide icons

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Brand

- Navy: `#051337`
- Orange: `#EB7B30`
- Logo: `public/brand/logo.png`
